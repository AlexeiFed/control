# Project Rules

- Отвечай пользователю на русском языке и давай прикладные решения без высокоуровневой воды.
- Перед изменениями кратко опиши план реализации, затем вноси изменения.
- Для UI всегда используй дизайн-токены из `src/lib/design-tokens.ts`; если файла нет, первым шагом создай его.
- Для ERP безопасности держи систему закрытой: публичной регистрации нет, первый администратор создаётся seed-скриптом, новые пользователи создаются только администратором.
- Любой доступ к страницам и API проверяй через session + RBAC. Не скрывай только UI: серверная проверка обязательна.
- Финансовые отчёты и табель доступны бухгалтеру и администратору; планировщик не должен видеть финансы и управление пользователями.
- Конфликты смен блокируются до записи: болезнь/отпуск охранника, пересечение смен, некорректные интервалы.
- После существенных изменений проверяй линтеры/тесты для затронутых файлов.
