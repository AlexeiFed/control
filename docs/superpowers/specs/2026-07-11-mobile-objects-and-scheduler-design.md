# Мобильные страницы «Объекты» и «Графики смен»

## Цель

Адаптировать страницы `/objects` и `/scheduler` для экранов уже `md`, не меняя существующий десктопный интерфейс и серверную бизнес-логику.

## Графики смен

### Компоновка

- Десктопная таблица остаётся текущей и отображается начиная с `md`.
- На мобильном каждый объект отображается отдельной карточкой.
- В карточке одновременно видны все 14 дней: две календарные строки по 7 дней.
- Заголовок карточки содержит название объекта, диапазон дат и суммарный дефицит плана.
- Ячейка дня содержит дату, сокращённые данные назначенных охранников, длительность смен и дефицит плана.
- Текущий день, выходные, праздники, дефицит и типы смен выделяются цветами из `src/lib/design-tokens.ts`.
- При нескольких сменах ячейка показывает компактный список; содержимое не увеличивает ширину календаря.

### Назначение смены

- Нажатие на свободную область дня или кнопку `+` открывает существующий сценарий быстрого назначения.
- На мобильном форма назначения занимает весь экран и прокручивается вертикально.
- Поля отображаются одним столбцом: тип смены, время, охранник, ставка и подтверждение.
- Основная кнопка назначения остаётся доступной в нижней части формы.
- Сохраняются текущие значения по умолчанию и последнее использованное время смены.
- Проверки болезни, отпуска, пересечений и некорректного интервала продолжают выполняться существующей серверной логикой.

### Просмотр и редактирование смен

- Нажатие на существующую смену открывает её текущий просмотр и доступные действия.
- Удаление, замена и регистрация инцидента сохраняют существующие permission-проверки.
- Drag-to-fill остаётся только в десктопной таблице.

## Объекты

### Компоновка

- Десктопная таблица остаётся текущей и отображается начиная с `md`.
- На мобильном каждый объект отображается отдельной карточкой.
- Карточка содержит название, адрес, статус, число охранников и статистику текущей недели.
- Основные действия: открыть объект, назначить охранников, изменить статус, открыть шаблон сменности и ставки.
- Удаление остаётся отдельным опасным действием с существующим подтверждением.

### Раскрываемые блоки

- Охранники, шаблон сменности и ставки раскрываются внутри выбранной карточки.
- Одновременно может быть открыт существующий управляемый блок; состояние не переносится между объектами.
- Формы внутри карточки выстраиваются в один столбец и используют полноширинные поля и кнопки.
- Поиск, фильтр статуса и создание объекта занимают всю ширину мобильного экрана.

## Компоненты и данные

- Мобильные представления используют те же props, вычисления и server actions, что и текущие компоненты.
- Общие вычисления смен, плана и дефицита выносятся в небольшие чистые функции, чтобы мобильный и десктопный UI не расходились.
- Новые API, хранилища состояния и изменения схемы данных не требуются.
- Серверные `requireSession`, `assertPermission` и проверки server actions остаются единственным источником авторизации.

## Адаптивность и доступность

- Мобильное представление: `< md`; десктопное: `md` и шире.
- Минимальная зона нажатия интерактивных элементов — 44 px, кроме компактного содержимого календарной ячейки; сама ячейка целиком интерактивна.
- Полноэкранная форма имеет `role="dialog"`, доступное название, закрытие кнопкой и блокировку прокрутки фона.
- Текст не является единственным индикатором статуса: используются подписи вместе с цветом.

## Ошибки

- Ошибки назначения отображаются существующими toast-сообщениями и не закрывают форму.
- Пустые списки объектов, охранников и смен получают явные мобильные состояния.
- Длинные названия и фамилии сокращаются визуально, но полное значение остаётся доступно через доступную подпись.

## Проверка

- TypeScript: `npm run lint`.
- Тесты расчёта данных мобильной календарной ячейки: смены, часы, дефицит, праздник и несколько смен.
- Проверка страниц на ширинах 320, 375, 390, 768 и desktop.
- Проверка назначения, замены, удаления и инцидента для ролей Administrator, Planner и Accountant.
- Проверка отсутствия горизонтальной прокрутки страницы на мобильном и неизменности десктопной таблицы.
